# Project formal verification contract

- Scope: changes that require protocol assessment; low-risk exclusions.
- Inventory: authoritative model/configuration list, relevant source and regression tests.
- Semantics: ownership and acceptance boundaries; safety and progress obligations.
- Assumptions: storage atomicity, failure detection, fairness and finite bounds.
- Toolchain: pinned checker source/checksum, supported runtime, setup and check commands.
- Gates: focused development checks and complete integration/release checks.
- Evidence: revision, command, outcome, counterexample or explored states, uncovered scenarios.

Keep this contract in the project; link the reusable skill without embedding project details in it.
