# Aria Internal v0.2.2

> 本文是 [`v0.2.2.md`](v0.2.2.md) 的中文版。

Aria 0.2.2 是 0.2 稳定线上的一个部署安全补丁。它包含 0.2.1 交付的完整
触发平台，并在全球推广前修复了精确版本升级计划的问题。

本内部快照通过 GitHub 仓库分发，不发布到 npm。

## 修复

- 用 `aria update plan --target-version <x.y.z>` 取代了嵌套的
  `aria update plan --version <x.y.z>` 选项。Commander 此前会把嵌套 flag
  解释为根 CLI 的版本 flag，打印已安装的 Aria 版本后直接退出，不创建
  升级计划。
- 新增进程级回归测试：调用构建出的 CLI，证明精确目标选择由
  `update plan` 命令正确解析。
- 更新分发指引，改用无歧义的选项名。应用层升级契约与持久化的目标
  `version` 字段保持不变。

## 升级指引

- 选择这个精确版本时使用 `aria update plan --target-version 0.2.2`，
  或使用 `aria update plan` 选择最新的完整不可变内部版本。
- 用分离式升级器应用生成的计划。已有的 0.1.6 与 0.2.1 安装仍是有效的
  回滚基线。
- 在评审过部署策略后，用 `ARIA_TRIGGER_RUNTIME=enabled` 显式启用定时
  执行。

## 分发保证

- 内部发布仅从精确合入的 `main` commit 构建。
- 发布资产与独立安装器在不可变预发布版本发布前均经校验和验证。
- 升级器在原子版本切换前立即复核目标版本与摘要。
