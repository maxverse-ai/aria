# Aria v0.4.8

> English version: [v0.4.8.md](v0.4.8.md)

Aria 0.4.8 改善 Codex 会话准备流程，防止已停止的运行在迟到的恢复响应到达后继续提交任务。

- 继续旧会话时请求仅含元数据的恢复响应，并使用独立的 60 秒恢复期限；请求继续携带模型、工作目录、sandbox 和 service tier 设置。
- 准备会话期间停止会结束本地等待，阻止后续任务提交，也覆盖外层执行容量已释放的情况；这不代表服务端恢复操作已取消。
- 恢复超时会说明本次新任务尚未提交，并保留原会话关联。任务提交超时会说明是否受理尚不确定，不自动重发输入。
- RPC 诊断记录耗时、响应字节数和迟到响应，不记录请求或历史正文。放弃等待的请求元数据有数量上限和过期清理；单个慢恢复不会触发共享进程重启。
- 受控 stdio 回归测试和 TLA+ 模型检查覆盖停止与恢复竞态、迟到响应、并发会话、资源清理及重连行为。

真实长会话的耗时改善和上下文连续性仍需使用隔离的原生会话数据验证。模拟测试和模型检查不代表生产性能测量。详情见[验证范围和证据](../CODEX_RESUME_VERIFICATION.md)。
