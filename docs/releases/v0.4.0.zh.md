# Aria Internal v0.4.0

> 本文是 [`v0.4.0.md`](v0.4.0.md) 的中文版。

Aria 0.4.0 把发布线推进到 0.4，并将受支持的运行时提升到 Node 24。这是
CLI 自 0.3.2 起就一直在预告的版本。

Node 20 已于 2026-04-30 停止维护，但此前仍被声明为受支持，而 space
原生工具辅助程序早已要求 22 或更高版本。构建与 CI 自 0.3.2 起就跑在
Node 24 上，因此本版本只是让声明与事实对齐。

本内部快照通过私有 GitHub 仓库分发，不发布到 npm。

## 变更

- `engines.node` 现在是 `>=24.0.0`，发布的产物面向 Node 24。在 Node 20
  或 22 上安装或升级会被安装器的引擎检查拒绝，报
  `release requires Node.js >=24.0.0`，而不是延后失败。
- 原生工具辅助程序检查要求 Node 24，执行空间不再运行部分受支持的配置。
- CLI 提示从提前预警变为当前要求的陈述：
  `Aria requires Node 24 or newer; this host runs v<version>`。

## 升级指引

- **先把主机迁移到 Node 24。** 安装器会拒绝在旧运行时上安装本版本，
  因此在运行时迁移前制定的升级计划无法应用。
- 然后使用 `aria update plan --target-version 0.4.0` 并应用生成的计划。
  应用操作是分离执行的；请关注持久化的操作 id，不要因为终端断开就
  假设失败。
- 在 supervisor、profile、渠道与控制台健康检查通过前，保留不可变的
  `internal-v0.3.2` 安装作为回滚基线。

## 继承

0.4.0 携带本线上的全部内容：0.3.0 的执行空间、无渠道受管 worker、
`/task` 命令、按引擎权限策略、控制台开发预览与渠道 profile schema v3；
0.3.1 的 Linux 分离式升级器身份修复；以及 0.3.2 的仅运行时 Node 24
迁移与测试套件超时预算。
