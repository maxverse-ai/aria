# Aria v0.4.1

Aria 0.4.1 修复了当配置的工作目录已被删除时，Claude Code agent 启动失败的问题。

## 修复

- `resolveWorkingDirectory()` 现在会在请求的 `cwd` 为空、不存在或不是目录时，自动降级到用户的主目录。显式请求的文件系统根目录、Home 根目录、系统目录和临时目录根仍会被拒绝。这解决了因运行时目录被删除而导致 Claude Code agent 报 `invalid cwd` 的问题。

## 升级指引

- 运行 `aria update plan --target-version 0.4.1` 并应用生成的计划，或直接从发布资产安装。
