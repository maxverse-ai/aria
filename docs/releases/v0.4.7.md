# Aria v0.4.7

> 中文版：[v0.4.7.zh.md](v0.4.7.zh.md)

Aria 0.4.7 reduces network overhead in verified host-local publication.

- Missing release assets upload in one batch. Recovery reconciles partial batch uploads without replacing existing assets.
- Once a Release ID is recorded, subsequent inspections query that release directly, avoiding repeated release-list pagination.
- All eight assets are downloaded and hashed. A second download is avoided only when remote asset IDs, names, sizes, SHA-256 digests, upload states and timestamps provide unchanged identity; incomplete metadata retains the second download, while changed identity stops publication.
- Stage logs separately report release inspection, batch upload, download verification, main/tag checks, publication and final tag verification.
- Fault tests cover partial batch completion, changed verified assets and fallback verification when metadata is unavailable.

Full exact-main validation and immutable publication remain required. Recovery never reuses downloaded verification evidence from an earlier invocation. See the [release policy](../RELEASE_POLICY.md).
