# Aria Internal v0.2.0

> 本文是 [`v0.2.0.md`](v0.2.0.md) 的中文版。

Aria 0.2.0 建立了共享的渠道可靠性层，引入了第一批只读的触发平台契约，
并将 supervisor 控制台翻新到 Astryx 设计系统。

本内部快照通过 GitHub 仓库分发，不发布到 npm。

## 新增

- 新增 `aria trigger capabilities` 与 `aria trigger schema <name>`，用于
  发现版本化的触发契约。本版本仍不开放定时执行。
- 新增执行意图目录、schema、校验与会话适配器，作为未来触发提供方的
  基础。
- 定义了触发提供方 ABI、注册契约与契约测试套件，但未启用提供方执行。
- 新增共享渠道可靠性原语：租约、重试、投递检查点、持久化文件状态与
  内存契约测试。
- 新增渠道实例解析与运行时的显式 Lark 会话归属投影。
- 新增微信客服渠道插件组装、归属管理，以及基于共享渠道契约构建的
  可靠消息出口。

## 控制台与运维

- 用 Astryx 替换了原 supervisor 控制台的组件层，翻新了配置、引导、
  profile 与运行时视图。
- 扩展只读控制面，提供新控制台与平台契约所需的渠道与触发状态。
- 把浏览器端类型检查纳入仓库的必选类型检查门禁。

## 升级指引

- 在常规升级预检确认没有进行中的会话后，全局 Aria 安装请使用
  `internal-v0.2.0`。
- 触发器 CLI 仅用于契约发现；本版本不运行定时任务或外部触发提供方。
- 现有 Lark profile 继续使用当前渠道配置；新的归属投影与可靠性层是
  增量式运行时基础。
- 在 supervisor、profile、渠道与控制台健康检查通过前，保留不可变的
  `internal-v0.1.6` 安装作为自动回滚基线。

## 分发保证

- 内部发布仅从精确合入的 `main` commit 构建。
- tarball、产物 manifest、校验文件、发布契约与独立安装器在草稿发布前
  均已验证。

  替换。
