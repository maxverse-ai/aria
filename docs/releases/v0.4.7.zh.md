# Aria v0.4.7

> English version: [v0.4.7.md](v0.4.7.md)

Aria 0.4.7 降低经过验证的本机发布流程中的网络开销。

- 缺失资产通过一次批量调用上传，恢复时核对已完成的部分，不覆盖已有资产。
- 记录 Release ID 后直接查询该发布，避免重复分页读取版本列表。
- 全部 8 项资产仍会下载并核验摘要；仅当远端资产 ID、名称、大小、SHA-256、上传状态和时间戳能证明身份未变时省去第二次下载。元数据不完整时保留第二次下载，身份变化时停止发布。
- 阶段日志分别展示发布查询、批量上传、下载校验、主线与标签检查、正式发布及最终标签验证。
- 故障测试覆盖批量上传部分成功、已验证资产发生变化，以及缺少元数据时的完整校验回退。

仍要求对准确的主线提交执行完整验证，并使用不可变发布。恢复操作不会复用上一次调用中的下载验证结果。详情见[发布策略](../RELEASE_POLICY.md)。
