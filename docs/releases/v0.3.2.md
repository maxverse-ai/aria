# Aria Internal v0.3.2

> 中文版：[v0.3.2.zh.md](v0.3.2.zh.md)

Aria 0.3.2 is a patch on the 0.3 line. Aria is now built and validated on
Node 24.21.0 (LTS); the supported runtime floor is unchanged, so no existing
installation has to move.

This internal snapshot is distributed through the private GitHub repository. It
is not published to npm.

## Changed

- Aria is built and validated on Node 24.21.0 (LTS). `engines.node` still
  allows `>=20.12.0` and the published bundles still target Node 20, so nothing
  in this release requires a runtime change.
- **The next MINOR release will require Node 24.** A host on an older runtime
  now prints `Aria 0.4 will require Node 24; this host runs v<version>` on every
  `aria` invocation, including service startup. Plan the runtime upgrade before
  then; `aria update plan --target-version 0.4.0` will fail closed on an older
  runtime once that release exists.
- The test suite gets a CI-sized timeout budget, and the three drifted copies of
  its async-work poll helper are now one shared helper whose budget survives a
  loaded runner.

## Upgrade guidance

- Use `aria update plan --target-version 0.3.2`, then apply the generated plan.
- No runtime change is required for this release. If the warning appears, it is
  the advance notice for 0.4, not a problem with this upgrade.
- Keep the immutable `internal-v0.3.1` installation as the rollback baseline
  until supervisor, profile, channel, and console health checks pass.
