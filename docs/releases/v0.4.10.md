# Aria v0.4.10

> 中文版：[v0.4.10.zh.md](v0.4.10.zh.md)

Aria 0.4.10 completes the system audit's 17 remediation items, strengthening
session cancellation, message ownership, crash recovery and update coordination.

- Session preparation respects cancellation before submitting prompts. ACP drains
  pending output at EOF, Codex checks nested turn identity, and Grok keeps
  historical replay separate from the current turn.
- Follow-up mailbox ownership survives notification failures and partial
  publication. Expired bodies are redacted while stable tombstones prevent
  consumed input from returning. Cross-process execution claims retain unknown
  outcomes for explicit reconciliation instead of blind replay.
- Managed-card sends with unknown outcomes no longer fall back to a second,
  untracked send. Trigger success and result delivery are durably linked through
  an outbox, with independent delivery claims and atomic UTC daily grant quotas.
- Keystore salt initialization and read-modify-write operations are serialized
  across processes. Update locks use immutable generations so stale cleanup
  cannot remove a replacement owner's lock.
- Updates persist authenticated admission holds, drain active work and verify
  the new instance's actual build identity and readiness. Rollback capability is
  checked before stopping the running instance. Legacy targets lacking the
  required capabilities are rejected by default; review the documented force
  bootstrap procedure before updating such installations.

Unknown execution or delivery outcomes require inspection and explicit
reconciliation; this release does not automatically repeat potentially completed
effects. See the [remediation ledger](../FORMAL_REMEDIATION_HANDOFF.md) for
individual fixes, recovery documentation and verification evidence.

Validation includes TLA+ counterexamples and corrected finite models, controlled
component regressions and independent-process fault tests. Live native Grok and
Feishu scenarios were not verified; these checks do not establish exactly-once
remote effects.
