# Aria v0.4.2

> 中文版：[v0.4.2.zh.md](v0.4.2.zh.md)

Aria 0.4.2 publishes the standalone embedded worker artifact used by trusted
Riff Desktop builds.

## Added

- GitHub Releases now include a separately bundled `aria-worker-0.4.2.tgz`
  with a commit-bound manifest and SHA-256 checksum.
- The worker bundle is built and verified from the exact release commit.

## Upgrade guidance

- Existing CLI installations can update normally. The worker asset is consumed
  by authorized embedding hosts and is not a new CLI command.
