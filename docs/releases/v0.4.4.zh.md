# Aria v0.4.4

> English version: [v0.4.4.md](v0.4.4.md)

Aria 0.4.4 将渠道指令与通用 Agent 执行分离，并支持经过验证的宿主机本地 GitHub Release 发布。

## 修复

- 通用入口和 Desktop 不再根据观测来源标签自动获得 Aria 人设或飞书指令。
  没有宿主提供的上下文时，用户文本原样透传，包括空白和类似协议的文本。
- 飞书消息、评论、doctor、会议和任务唤醒入口显式保留渠道指令。
  原生权限、隔离、参与者身份及启用的 notice+pull steering 契约保持有效。
- 没有显式渠道上下文时，通用引擎启动不再自行增加 `LARK_CHANNEL=1`；
  可信飞书 profile 的绑定保持可用。
- Windows 工具链检查支持命令 shim，worker 校验兼容原生 tar 输出的 CRLF 换行。

## 发布方式

CI/CD 保持停用。正式发布由宿主机完成：验证准确的 main 提交、持有仓库独占锁、
重新下载并校验草稿资产，最后核验正式 Release 不可变。npm 发布不受支持。
详情见[发布策略](../RELEASE_POLICY.md)。

## 升级提示

嵌入宿主需要固定正式 worker 的 revision 和校验和。请使用新建的原生会话验证提示词边界，
旧会话历史可能仍包含早期指令。本次更新不会清除原生配置或历史，不会改写模型回复，
也不能据此认定认证状态或模型能力。
