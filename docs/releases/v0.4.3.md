# Aria v0.4.3

> 中文版：[v0.4.3.zh.md](v0.4.3.zh.md)

Aria 0.4.3 makes the embedded worker Release asset self-contained for trusted
embedding hosts such as Riff Desktop.

## Fixed

- Worker Release bundles no longer require an Aria `node_modules` tree at the
  embedding host.
- QR rendering remains explicitly unavailable in embedded worker mode.

## Upgrade guidance

- Existing CLI installations can update normally. The worker asset is consumed
  by authorized embedding hosts.
