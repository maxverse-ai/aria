# Aria v0.4.6

> 中文版：[v0.4.6.zh.md](v0.4.6.zh.md)

Aria 0.4.6 improves the reliability and visibility of host-local GitHub Release publication.

## Publication improvements

- `pnpm release:preflight` checks the toolchain, GitHub permissions, immutable release settings, exact remote-main checkout, target collisions and prepared bilingual notes before expensive validation.
- `pnpm release:plan` now checks the package version against tags and published GitHub Releases; `release:status` remains a compatible alias.
- Publication builds once, runs the full test and typecheck gates, then packages the same output without redundant builds.
- Stage logs report progress, outcomes and elapsed time, with local session records identifying the tested commit, toolchain and all eight asset digests.
- `pnpm release:resume` reconciles interrupted creation, upload or publication against actual GitHub state. It uploads only missing assets, rejects conflicting inputs and verifies downloaded assets and the published tag before reporting success.

## Operational guidance

Resume requires the original clean checkout, unchanged artifacts and matching toolchain at the exact current main commit. Keep the release workspace until publication and verification finish. These improvements retain host-local execution, full validation, immutable releases and the prohibition on overwriting published assets.

See the [release policy](../RELEASE_POLICY.md) for commands and recovery requirements.
