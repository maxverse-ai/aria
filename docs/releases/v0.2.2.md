# Aria Internal v0.2.2

Aria 0.2.2 is a deployment-safety patch on the 0.2 stable line. It contains
the complete Trigger Platform delivered in 0.2.1 and fixes exact-version update
planning before the global rollout.

This internal snapshot is distributed through the private GitHub repository. It
is not published to npm.

## Fixed

- Replaced the nested `aria update plan --version <x.y.z>` option with
  `aria update plan --target-version <x.y.z>`. Commander previously interpreted
  the nested flag as the root CLI version flag, printed the installed Aria
  version, and exited without creating an update plan.
- Added a process-level regression test that invokes the built CLI and proves
  exact target selection is parsed by the `update plan` command.
- Updated distribution guidance to use the unambiguous option name. The
  application-layer update contract and persisted target `version` field are
  unchanged.

## Upgrade guidance

- Use `aria update plan --target-version 0.2.2` when selecting this exact
  release, or `aria update plan` to select the newest complete immutable
  internal release.
- Apply the generated plan with the detached updater. Existing 0.1.6 and 0.2.1
  installations remain valid rollback baselines.
- Enable scheduled execution explicitly with
  `ARIA_TRIGGER_RUNTIME=enabled` after deployment policy has been reviewed.

## Distribution guarantees

- The internal release is created only from the exact merged `main` commit.
- Release assets and the standalone installer are checksum-verified before the
  immutable prerelease is published.
- The updater revalidates the target release and digest immediately before the
  atomic version switch.
