# Aria Internal v0.3.2

> 本文是 [`v0.3.2.md`](v0.3.2.md) 的中文版。

Aria 0.3.2 是 0.3 线上的一个补丁。Aria 现在在 Node 24.21.0（LTS）上
构建并验证；受支持的运行时下限不变，现有安装无需迁移。

本内部快照通过私有 GitHub 仓库分发，不发布到 npm。

## 变更

- Aria 在 Node 24.21.0（LTS）上构建并验证。`engines.node` 仍允许
  `>=20.12.0`，发布的产物仍面向 Node 20，因此本版本不要求更换运行时。
- **下一个 MINOR 版本将要求 Node 24。** 运行旧版运行时上的主机，现在会
  在每次 `aria` 调用时打印
  `Aria 0.4 will require Node 24; this host runs v<version>`，包括服务
  启动时。请在此之前规划运行时升级；该版本发布后，
  `aria update plan --target-version 0.4.0` 会在旧运行时上关闭失败。
- 测试套件获得与 CI 匹配的超时预算，三份各自漂移的异步工作轮询辅助
  函数合并为一个共享实现，其预算在负载较高的 runner 上也能撑住。

## 升级指引

- 使用 `aria update plan --target-version 0.3.2`，然后应用生成的计划。
- 本版本不要求更换运行时。如果出现警告，那是针对 0.4 的提前通知，
  而不是本次升级的问题。
- 在 supervisor、profile、渠道与控制台健康检查通过前，保留不可变的
  `internal-v0.3.1` 安装作为回滚基线。
