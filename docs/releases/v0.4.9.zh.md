# Aria v0.4.9

> English version: [v0.4.9.md](v0.4.9.md)

Aria 0.4.9 修复追加指令信箱、执行并发许可、Codex 重连和卡片回调中的所有权竞态。

- 信箱消费者跨进程排他领取正文。已知任务拒绝会释放领取；提交结果未知时
  保留记录供核查，不自动重放。同一请求 ID 不再复活已消费消息。
- 并发池在唤醒等待者前为其保留许可，重复释放不会释放其他运行的容量。
- Codex 重连后重新订阅引擎主动启动任务的通知，并解绑已关闭连接的订阅。
- 卡片操作在 dispatcher 开始 I/O 前返回，通过共享后台执行器继续按序处理。
- 接管旧安装时探测实际 CLI 版本并解析 npm 命令 shim，避免包元数据与可执行
  版本不同导致回滚基线校验失败。

TLA+ 检查覆盖信箱所有者退出及提交结果未知。真实组件、子进程和任务流程回归
验证修复后的边界；不代表 agent 副作用恰好执行一次、模型已经读到 CLI 输出，
或飞书线上回调延迟已经实测。详情见[修复证据](../RUNTIME_OWNERSHIP_IMPLEMENTATION.md)
及[信箱恢复边界](../STEERING.zh.md)。
