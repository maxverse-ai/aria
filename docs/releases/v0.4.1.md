# Aria v0.4.1

> 中文版：[v0.4.1.zh.md](v0.4.1.zh.md)

Aria 0.4.1 fixes Claude Code agent startup when the configured working directory has been removed.

## Fixed

- `resolveWorkingDirectory()` now falls back to the user's home directory when the requested `cwd` is empty, missing, or not a directory. Explicitly requested filesystem roots, home root, system directories, and temp roots are still rejected. This resolves `invalid cwd` errors for Claude Code agents launched against deleted runtime directories.

## Upgrade guidance

- Run `aria update plan --target-version 0.4.1` and apply the plan, or install from the release assets.
