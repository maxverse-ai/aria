# Aria v0.4.4

> 中文版：[v0.4.4.zh.md](v0.4.4.zh.md)

Aria 0.4.4 separates channel instructions from generic Agent execution and
supports verified host-local GitHub Release publication.

## Fixed

- Generic and Desktop requests no longer acquire an Aria persona or implicit
  Feishu instructions from observability source labels. Without host context,
  user text is forwarded unchanged, including whitespace and protocol-like text.
- Feishu messages, comments, doctor, meetings and task wakeups explicitly retain
  their channel instructions. Native permissions, isolation, participant identity
  and enabled notice+pull steering contracts remain enforced.
- Generic engine launches no longer introduce `LARK_CHANNEL=1` without explicit
  channel context. Trusted Feishu profile bindings remain available.
- Windows toolchain checks support command shims; worker verification accepts
  native CRLF tar listings.

## Publication

CI/CD remains disabled. The supported host-local publisher runs exact-main gates,
uses an exclusive repository lock, verifies uploaded draft assets by downloading
them, and verifies the stable release is immutable. npm publication is unsupported.
See [release policy](../RELEASE_POLICY.md).

## Upgrade guidance

Embedding hosts must pin the published worker revision and checksum. Validate the
changed prompt boundary in a fresh native conversation: existing resumed history
can retain earlier instructions. This release does not clear native settings or
history, rewrite model answers, or establish authentication/model capabilities.
