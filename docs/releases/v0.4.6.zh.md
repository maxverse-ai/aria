# Aria v0.4.6

> English version: [v0.4.6.md](v0.4.6.md)

Aria 0.4.6 改进宿主机本地 GitHub Release 发布流程的可靠性和进度展示。

## 发布流程改进

- 新增 `pnpm release:preflight`，在耗时验证前检查工具链、GitHub 权限、不可变发布设置、准确的远端主线提交、目标版本冲突和已准备的双语说明。
- `pnpm release:plan` 统一核对包版本、标签和 GitHub 正式版本；`release:status` 保留为兼容入口。
- 正式发布构建一次，运行完整测试和类型检查，再使用同一套构建输出打包，避免重复构建。
- 阶段日志展示进度、结果和耗时，本地会话记录标识已验证的提交、工具链及全部 8 项资产摘要。
- 新增 `pnpm release:resume`，根据 GitHub 实际状态恢复中断的创建、上传或发布操作，仅上传缺失资产，拒绝冲突输入，并在下载资产和发布标签校验通过后报告成功。

## 操作提示

恢复要求保留原来的干净工作区、未变化的资产和匹配的工具链，并且仍处于准确的当前主线提交。请在发布及验证完成前保留发布工作区。本次改进继续遵守本机执行、完整验证、不可变发布和禁止覆盖已发布资产的要求。

命令和恢复条件详见[发布策略](../RELEASE_POLICY.md)。
